Your AI agent, oriented in one call

Unreal 5.8's MCP tools describe assets in full, and every session starts cold. Project Map answers the questions an agent asks first, in a few hundred tokens.

project_overview

Engine, C++ modules, plugins, default map and game mode, maps, asset counts per folder and class.

find_assets

Every asset whose name matches, optionally of one class.

asset_dependencies

What an asset uses and what uses it, up to four hops. Check before renaming or deleting.

blueprint_summary

Parent, interfaces, components, variables, functions and graphs, without the node dump.

material_summary

Parent, parameters with values and textures, without the expression graph.

Install

  1. Install the plugin from Fab to the engine, or copy it to YourProject/Plugins/ProjectMap.
  2. Enable Project Map for AI Agents, Model Context Protocol and All Toolsets in Edit > Plugins, then restart.
  3. In the editor console: ModelContextProtocol.StartServer 18765, then ModelContextProtocol.GenerateClientConfig ClaudeCode, or point any MCP client at http://127.0.0.1:18765/mcp.
  4. Tell your agent: “Call project_overview first, then use find_assets and asset_dependencies before you change anything.”

The toolset is project_map.toolset.ProjectMapTools; with tool search on, call it through call_tool. Every argument except the asset path is optional.

Python

from project_map import context
print(context.to_json(context.project_overview()))
print(context.to_json(context.asset_dependencies("/Game/Characters/BP_Hero", "both", 2)))

Notes

  • Read-only: nothing is renamed, moved, saved or deleted.
  • Dependencies come from the Asset Registry: assets loaded only by config or by soft paths built at runtime have no edge.
  • blueprint_summary and material_summary load the asset they describe.
  • Requires Unreal Engine 5.8. The MCP plugin is Experimental in 5.8.

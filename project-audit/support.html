Help with Project Audit Pro

Support

Start with the topics below, or send a report if something isn’t working.

Tools > Project Audit is missing

Check that Project Audit Pro and Python Editor Script Plugin are enabled in Edit > Plugins, then restart the editor. The Output Log shows Registering Toolset project_audit_pro... when the plugin loaded.

My agent can’t see the tools

Enable Model Context Protocol and All Toolsets, restart, run ModelContextProtocol.StartServer 18765 in the editor console and point the client at http://127.0.0.1:18765/mcp. With tool search on, the tools are reached through call_tool with the toolset name project_audit_pro.toolset.ProjectAuditProTools.

An asset is reported unreferenced but the game uses it

Assets loaded by config, by soft paths built at runtime or by Primary Asset rules have no reference the Asset Registry can see. Add their folder to unreferenced.ignore_paths in Config/ProjectAudit.json. Quarantine instead of deleting, play-test, then delete the quarantine folder.

CI fails on something we accept

Raise that check’s limit in fail_on, or set it to null to report it without failing. Exit code 2 means the audit could not run; the log above it says why.

Undo a fix

Fixes save the assets they change. Revert them in source control. That is why every fix shows a preview and asks first.

Report a problem

Include your engine version, operating system, what you ran and the Output Log lines with ProjectAudit in them.

Email support Open a support request

The GitHub support tracker is public. Don’t post order numbers, account details or files from a project you can’t share.
